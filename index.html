Untitled

A little Markdown help

Select text, then choose a toolbar button. Without a selection, buttons insert an example or format the current line. Replace the selected example with your own words.

Headings
# Title
## Section
### Subsection
Bold and italic
**bold text**
*italic text*
Links
[link text](https://example.com)

The words go in brackets; the address goes in parentheses.

Lists
- First item
- Second item

Use 1. and 2. for numbered lists.

Checklists
- [ ] To do
- [x] Done
Quotes
> A quotation
Code
`inline code`

```
A block of code
```
Tables
| Name | Value |
| --- | --- |
| Example | 42 |

Keep the separator row beneath your column headings.

Leave a blank line between paragraphs. Watch the preview as you type. Use ⌘B for bold, ⌘I for italic, and ⌘K for links.
